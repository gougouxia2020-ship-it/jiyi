## 四、调色分级参数与理由

纯 PIL（Pillow 12.3.0）实现，无 numpy / ImageMagick。管线顺序与逐步理由：

1. **降饱和** `ImageEnhance.Color(im).enhance(0.60→0.46)`
   - 主手段。目标把 S 压进 15%–37% 组内。经 color 因子扫描（0.44→38.4%…）确定 **0.46 → 35.4%**：贴近卧室 37% 略低、稳在组内，且不至于灰到失去书房该有的暖色层次。理由：书房本是三张里最花的一张（满架彩色书脊 + 芥末黄 / 陶土红抱枕），压过头会显脏、压不够又是孤例，35% 是「明显在组内 + 明显已改」的平衡点。

2. **褪色对比曲线**（抬黑 `black_lift=20` / 压白 `white_cap=242`，分通道 LUT 内先做）
   - 低对比 matte 胶片 + 旧纸褪色感的核心。把纯黑抬到 ~20、纯白压到 ~242，压缩动态范围——原图那扇过曝惨白的窗被拉回带暖雾的褪色高光，对齐 design.md「不用纯白 / 低饱和旧纸色」与卧室/客厅的褪色胶片调。

3. **暖色偏移**（分通道 LUT：R gain 1.025 / off +5，G gain 1.00 / off +1，B gain 0.945 / off −5）
   - 增红微降蓝的整体暖调。刻意用「小 gain 分歧 + offset 暖移」而非大 gain 分歧：大 gain 分歧会在高饱和像素上把 S 又顶回去（早期试验 R×1.055/B×0.905 时 color=0.55 仍有 38.8%），改用温和 gain + 暖 offset，暖味来自整体色偏而非给鲜艳块加彩，饱和度才压得下来、暖调也更接近卧室的琥珀胶片而非橙到失真。

4. **胶片颗粒** `os.urandom` 噪点 → 压到 128 附近（`grain_amp=0.15`）→ `ImageChops.overlay` 混合
   - 全分辨率均匀噪点压成 ±小幅偏离、以 128 中性灰做 overlay 混合：中性处不改、偏离处叠细颗粒，均值不移故不干扰饱和度测量。amp 0.15 使颗粒在平滑面（坐垫/墙）肉眼可辨而不到脏点程度，补检察员点名缺失的「胶片颗粒」。

5. **暗角 / 边缘褪色**（低分辨率算径向亮度遮罩再 BICUBIC 放大：`edge_min=0.80` / `power=2.4`；边缘再 `vig_desat=0.85` 轻去饱和按遮罩混入）
   - 径向遮罩中心保持不动、四角压到 80% 亮度做暗角；同一遮罩把边缘的轻去饱和版本混进来，边角更灰更旧——补「暗角 / 褪色」质感，与卧室的重暗角、客厅的边缘空气感成一路。低分辨率算遮罩再放大：纯 Python 逐像素算 6M 太慢，360×240 算好再 BICUBIC 上采样，平滑无带、够快。

胶片旧信 DNA 落点：整体暖琥珀色偏（暖）+ 低对比抬黑压白（褪色/旧纸）+ 细颗粒（胶片）+ 四角暗角（做旧）——四样叠齐，正是检察员点名缺的三样（低饱和、胶片颗粒、暗角褪色）加上原有暖调的强化。
